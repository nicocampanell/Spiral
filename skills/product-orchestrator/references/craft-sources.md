## Technical references

- [WCAG text contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): normal/large text ratios and actual exceptions.
- [WCAG target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html): 24 CSS px or criterion-specific exceptions, distinct from a 44px usability target.
- [WCAG reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html): 320 CSS px and necessary two-dimensional-content exceptions.
- [Apple accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility.md): native text scaling, control defaults, gesture alternatives and assistive input. Current iOS table distinguishes 44pt default from 28pt minimum.
- [Android accessibility](https://developer.android.com/guide/topics/ui/accessibility/apps): recommended 48dp targets and platform semantics.

## Conflict resolution

The user brief, approved direction, actual platform and existing coherent system govern stylistic choices. Technical failures and false claims need repair, not a style exemption. Use 4/8 spacing and a 2–3-family maximum budget as defaults, not a quota or an instruction to replace established tokens. Keep a valid single-family design and native system typography.

Do not import rigid font blacklists, radius recipes, mandatory motion, universal 200 ms limits, fixed translation-expansion percentages or blanket card/gradient bans. Do not globally disable autocomplete, paste, scroll/zoom or system focus. Use relevant native behavior and current technical requirements.

Humanizer and Vercel disagree on curly versus straight quotes; preserve the target format and product voice, with code/identifiers unchanged. Their punctuation and passive-voice prescriptions are heuristics, not proof of AI authorship. Preserve necessary uncertainty and domain qualifications, and never invent numerical specificity.

Treat upstream examples critically. The reviewed Vercel localStorage migration example can remove the old key after its new-key save swallowed an error. Our integrity floor explicitly requires confirmed replacement before deleting prior valid data. Likewise, do not copy framework/provider choices, model names, publishing actions or organization-specific document metadata as universal laws.
